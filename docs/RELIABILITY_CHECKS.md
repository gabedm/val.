# Reliability checks

Run type checks, the regression suite, a production build, formatting and source scanning before release. Use disposable databases only.

For live acceptance, use a fresh account session and blank needs. Walk through login, import, onboarding, alternatives, reload and a naturally due scheduled check. Check that all three tabs show the same saved state.

Test unfamiliar subscriptions, spelling mistakes, short answers, corrections, provider timeouts, incomplete quotes, expired sessions, duplicate clicks and restarts.

For switching, verify purchase approval, activation before cancellation, cancellation confirmation and safe recovery after an unknown result. Simulated services prove application behaviour; real Sandbox transactions prove only the tested integration path.

Record source version and observed results. Do not replace a failed live result with a fixture or force a completion state.
