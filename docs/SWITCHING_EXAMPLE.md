# Optional switch example

Public installations leave `VAL_SWITCH_EXAMPLE=false`. No hosted provider account, operator key or test agreement is included.

A separate judge installation may configure its own controlled Sandbox provider. The visitor selects a subscription; Val creates an isolated test copy and preserves the original portfolio. The normal switching engine prepares terms, requests approval, verifies activation, cancels the test renewal and verifies the result.

Preconnected fictitious Sandbox funding can avoid another checkout. Otherwise the visitor may need to approve through PayPal. No real subscription is cancelled by this example.

A successful example proves that tested Sandbox path. Commercial-provider support and production permission remain separate. See [switching](SUBSCRIPTION_SWITCHING.md).
