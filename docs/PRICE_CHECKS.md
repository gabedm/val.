# Price checks

Ask for a cadence in chat, for all subscriptions or just one. Val proposes the change; confirmation saves it. Each subscription keeps its own schedule.

Workers use durable jobs and leases. Reloading reconnects to existing work rather than starting another request. Updated needs invalidate outdated advice.

Saved results remain readable during access, budget or provider failures. Incomplete research is not treated as a completed search with no match. Unknown model outcomes retain their cost holds.

The server must be running for checks to execute. Hosted installations need a persistent database, an active worker and an allowance that covers scheduled work.
